POS — Akhiri Shift, 3 alternatif

Interaktif: absen keluar, isi nominal tiap kanal, hitung uang fisik, lalu tutup shift.

A · Wizard 3 langkah

Periksa → Absensi → Cocokkan. Satu hal per layar, progres jelas, tombol Lanjut hanya aktif bila langkah beres.

B · Satu halaman + bar total

Checklist kesiapan di atas, kanal pembayaran di bawah. Bar bawah menempel: Sistem · Aktual · Selisih live, dengan alasan kenapa tombol belum aktif.

C · Tile kanal + geser tutup

Kanal berupa tile dengan status. Ring progres, banner kesiapan, lalu geser untuk menutup. Cocok untuk banyak kanal.
