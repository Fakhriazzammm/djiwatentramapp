POS /pesanan — 3 alternatif (lanjutan dari Rail)

Interaktif: filter, ganti tab, geser baris, tap untuk detail, bayar / hapus / cetak.

A · Ringkasan + daftar swipe

Ringkasan omzet di atas, tab Riwayat/Open Bill satu segmen, filter jadi chip yang membuka sheet. Geser baris untuk Cetak/Bayar.

B · Kartu status + accordion

Open Bill digabung jadi filter status (bukan tab terpisah). Kartu dibuka inline: item, cetak, bayar, hapus tanpa pindah layar.

C · Master-detail + mode pilih

Daftar rapat + pencarian. Tap membuka halaman detail dengan timeline; tahan/“Pilih” untuk aksi massal (cetak/hapus Open Bill).
