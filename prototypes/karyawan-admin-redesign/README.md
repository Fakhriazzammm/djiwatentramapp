# Redesain Admin › Karyawan (prototipe)

Buka `index.html` di browser. Tab 1 = alur pengguna, tab 2 = desain 8 halaman (klik menu kiri; klik baris Data Karyawan untuk panel samping; klik item di Cuti & Izin).
Mengikuti Djiwa Soft iOS (`docs/design-system/DJIWA_DESIGN_SYSTEM.md`). Data contoh; belum ada kode produksi. Ikon emoji di prototipe adalah placeholder untuk `Djiwa3DIcon` (employee-profile, employee-attendance-check-in, work-schedule, payroll-payslip, dll.).
