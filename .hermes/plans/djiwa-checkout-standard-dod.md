# Djiwa Checkout Standard — Definition of Done

- [x] Shared checkout UI package exists with typed reusable components and one-surface card rules.
- [x] Djiwa Pay confirmation step consumes shared header, payment method, summary, notice, and action components.
- [x] Djiwa Pay and QRIS behavior remains unchanged: wallet balance gate, QRIS redirect, back action, and payment CTA.
- [x] Customer app checkout remains behaviorally untouched; its existing layout is the visual reference.
- [x] Shared package and Djiwa Pay typechecks pass.
- [x] Djiwa Pay production build passes.
- [x] Diff is whitespace-clean and only intended files are staged.
- [x] Local preview HTTP response and bundled asset markers are verified.
- [ ] Production release is pending explicit deployment approval.
- [x] Visual preview evidence is captured or a deterministic DOM/CSS preview is recorded.
